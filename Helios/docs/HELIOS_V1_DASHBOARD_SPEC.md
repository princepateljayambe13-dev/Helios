# 1. Executive Summary & Design Philosophy

The HELIOS Dashboard provides a military/defense-grade operational Security Operations Center (SOC) interface. Designed specifically for high-intensity control rooms, it features:
- **Glassmorphic Tactical Aesthetics**: Deep onyx background (`#0D0E12`), translucent frosted cards (`backdrop-filter: blur(16px)`), subtle gold/bronze accent borders (`#C99A5B`), and vivid glowing status indicators (`#E53935` Red, `#00E676` Green, `#00E5FF` Cyan).
- **Zero Page-Refresh Dynamic Stream**: Powered by `useHeliosWebSocket`, views dynamically update tracks, events, incidents, and camera statuses without full re-renders.
- **Global Command & AI Hub (`⌘ K`)**: Universal keyboard shortcut opening search across cameras, tracks, and license plates paired with direct AI prompt execution.
- **Synthesized Audio Alerting**: Procedural Web Audio chimes for critical threat alerting.

# 3. Complete View Inventory (12 Views)

### 3.1 `Overview` (`HeroOverview`, `NarrativeGrid`, `SurveillanceGlobe`)
The command home screen:
- **Status Spectrum Ring**: Animated CSS pulsing ring indicating `ALL SYSTEMS SECURE` vs `INTRUSION DETECTED`.
- **24-Hour Threat SVG Sparklines**: Real-time hourly event density curves.
- **Live Narrative Cards**: Real-time micro-narratives generated by the AI narrator.
- **3D Surveillance Globe**: Interactive rotating globe showing tactical facility nodes.

### 3.2 `LiveFeedsView`
Interactive camera matrix supporting $1 \times 1$, $2 \times 2$, or full-screen view. Renders real-time bounding boxes, velocity tags, and person names over live video canvas.

### 3.3 `FencingView`
Perimeter management interface. Operators can click-to-draw custom vector polygons, designate tripwires, and configure loitering sensitivity directly over live camera snapshots.

### 3.4 `EventsView` & `ZoneEventsView`
Categorized event inspection:
- `All events`: Chronological log of all detections and state breaches.
- `Tracked events`: Events bound to continuous object tracks.
- `Zone events`: Perimeter breaches and tripwire crossings.

### 3.5 `InsightsView`
Strategic intelligence dashboard displaying the 7-signal composite insight cards, baseline deviation delta bars ("What Changed"), rolling activity digests, and the natural language investigation prompt bar.

### 3.6 `IncidentsView`
Multi-camera correlated incident management. Displays incident triage cards, status badges (`DETECTED`, `ACTIVE`, `RESOLVED`), visual chronological timelines, and correlation reasoning inspector.

### 3.7 `AlertsView`
High-priority alert triage station with one-click single/bulk acknowledgement, audio test buttons, and severity filtering.

### 3.8 `SystemLogsView`
Structured audit log explorer displaying backend log outputs, error traces, and operator interaction histories.

### 3.9 `EvidenceView`
High-resolution evidence gallery displaying captured full frames, cropped bounding box thumbnails, perceptual hash match indicators, and direct JPEG download options.

### 3.10 `ActivityThreadsView`
Spatial kinematic explorer showing tracked object journeys across multiple camera handoffs, complete with speed profiles, duration, and movement state changes.

### 3.11 `FacialRecognitionView`
Biometric intelligence center:
- Live face sighting stream with similarity score meters.
- Unclassified face association drawer to bind detections to known identities.
- Enrolled personnel roster directory with portrait upload and role tagging.

### 3.12 `SettingsView`
Platform settings management for camera RTSP/UDP endpoints, zone thresholds, model confidence sliders, and storage retention policies.

# 5. Real-Time WebSocket Hook (`useHeliosWebSocket.js`)

- Manages persistent connection to `ws://127.0.0.1:8000/api/v1/ws`.
- Emits reactive state updates across `lastEvent`, `lastAlert`, `lastIncident`, and `activeTracks`.
- Features exponential backoff reconnection logic (1s, 2s, 4s, up to 10s max interval).
- Updates top bar indicator with `LIVE`, `RECONNECTING`, or `DISCONNECTED`.
